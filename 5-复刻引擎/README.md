# 仙剑奇侠传-忘情篇 复刻引擎

纯Python实现的终端版复刻引擎，无需额外依赖。

## 环境要求
- Python 3.8+
- 无需 pygame/Pillow/Node.js

## 运行方式

### 文本模式（推荐，当前可用）
```bash
cd /mnt/shared/仙剑奇侠传忘情篇-逆向工程/5-复刻引擎
python3 game.py
```

### Curses图形模式（需要支持256色的终端）
```bash
python3 engine.py
```

## 操作说明

### 探索模式
- **W/↑** 向上移动
- **S/↓** 向下移动  
- **A/←** 向左移动
- **D/→** 向右移动
- **E** 与NPC交互
- **H** 查看帮助
- **M** 打开菜单
- **ESC/Q** 退出

### 战斗模式
- **1** 普通攻击
- **2** 使用技能
- **3** 使用物品
- **4** 逃跑

## 项目结构

```
5-复刻引擎/
├── png_decoder.py    # 纯Python PNG解码器（支持索引颜色）
├── map_parser.py     # 地图脚本解析器
├── config_parser.py  # 配置数据解析器
├── combat.py         # 回合制战斗系统
├── renderer.py       # Curses渲染器
├── engine.py         # 完整Curses引擎
└── game.py           # 文本模式主入口
```

## 已实现功能

1. **地图系统** - 解析69张地图脚本，提取NPC位置、对话、传送点
2. **角色系统** - 重楼（主角）、月瑶、紫萱三位角色
3. **战斗系统** - 回合制战斗，支持普通攻击、仙术、物品、逃跑
4. **升级系统** - 经验值、等级、属性成长
5. **对话系统** - 剧情对话触发
6. **PNG解码** - 纯Python实现，支持所有颜色类型

## 验证方式

你可以通过以下方式验证：

1. **运行文本版**: `python3 game.py` 进入交互式游戏
2. **测试战斗**: 走动时随机遭遇战斗，测试攻击/技能/物品
3. **检查地图**: 查看69张地图是否正确加载
4. **验证数据**: 对比3-数据/中的JSON配置与实际游戏行为
5. **图片验证**: 运行 `python3 png_decoder.py` 检查图片解码

## 技术说明

由于环境限制（无apt-get、无pip、无pygame），本引擎使用：
- 纯Python stdlib实现PNG解码（zlib）
- curses或纯文本输出
- 自定义配置解析器处理游戏数据格式
