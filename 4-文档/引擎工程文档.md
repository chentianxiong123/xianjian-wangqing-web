# 仙剑奇侠传-忘情篇 复刻引擎工程文档

## 概述

纯Python实现的终端版复刻引擎，无外部依赖。基于逆向工程解包的69张地图脚本、410张PNG图片、12个配置表构建。

## 环境

- **限制**: 无apt-get, 无pip, 无pygame, 无Pillow, 无Node.js
- **方案**: 纯Python stdlib (zlib解PNG, curses渲染)
- **Python**: 3.8.10

## 架构

```
5-复刻引擎/
├── png_decoder.py    # PNG解码（支持ctype=3索引颜色）
├── map_parser.py     # 地图脚本解析器
├── config_parser.py  # 配置数据解析器
├── combat.py         # 回合制战斗系统
├── renderer.py       # Curses渲染器
├── engine.py         # 完整Curses引擎（需要终端支持）
└── game.py           # 文本模式主入口（推荐）
```

## 文件格式

### MAP (地图脚本)
- 魔数: `88 4D 41 50`
- 16字节二进制头 + UTF-8脚本
- 命令格式: `对象.方法(参数);`

```
world.setName("地图名");
npc.setPosition(id, x, y)[条件];
dialogBox.setText(/NPC名/: 对话内容);
game.fight(怪物ID列表, 战斗背景, 音乐);
world.change(目标地图, 地砖bin, 动画ant, 精灵bin, x, y, 方向);
```

### ANT (动画)
- 魔数: `88 41 4E 54`
- 版本2，自定义二进制格式
- 16字节头 + 帧表(每帧4字节) + 图像数据
- **状态**: 未完全解码，精灵使用BIN中的静态PNG

### BIN (资源包)
- 魔数: `88 BIN`
- 包含多个PNG图片
- 目录结构: `图片/bin名/图片名.png.png`

### STR (剧本)
- 魔数: `88 STR`
- gzip压缩 + UTF-8文本
- 格式: `dialogBox.setText(/NPC/: 内容);`

## 战斗系统

### 属性
- 武(攻击)、防(防御)、速(速度)、精(HP)、气(SP)、神(IP)

### 伤害公式
```
物理伤害 = max(1, 攻击方武 - 防守方防/3 + random(-3,5))
技能伤害 = eval(技能power表达式)
```

### 技能示例
| 技能 | 类型 | 消耗 | 效果 |
|------|------|------|------|
| 心波 | 普通攻击 | 15SP | (atk*2)/3 单体 |
| 鬼降 | 普通攻击 | 10SP | (atk*8)/10 全体 |
| 炎咒 | 火系 | 12SP | 单体火系伤害 |
| 冰咒 | 水系 | 12SP | 单体水系伤害 |
