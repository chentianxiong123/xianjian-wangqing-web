## 怎么复现

```bash
cd 5-复刻引擎/web
python3 -m http.server 8901
# 浏览器打开 http://localhost:8901/game.html
```

引擎调试入口：`index.html`（带日志的调试宿主）；`game.html` 是无日志的正式页。
本次截图只在 `game.html` 上操作，且所有状态都是**真实走脚本/指令**摆出来的
（开场是 `newGame()` 后按回车推进，战斗/对话/商店都是引擎自己的 API 真实执行），
没有伪造画面，也没有为截图改任何引擎代码。

## 注意

- 截图只覆盖能跑通的那部分（结案说明里记的 20.6% 剧情覆盖率）；大量地图/剧情仍然播不出来，
  所以这里只有 7 张，不代表游戏内容就这些。
- 按既定规矩，**截图不用来验证剧情正确性**（那件事靠静态符号执行 + `XJ_TRACE` 文本对账），
  这里只作画面存档。
