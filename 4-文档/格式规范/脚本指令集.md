## 1. 解析前端（三者一致）

```
① 整行 trim，去掉结尾的 ';'
② d.c(line)   切分为多行（脚本可内嵌换行）
③ d.d(line)   取【指令名】= 第 2 个 token
④ d.e(line)   取【参数数组】= 第 3 个 token 起的括号内容
⑤ d.g(line)   取【条件数组】= 首 token 若为条件则取其括号内容
⑥ d.f(line)   取括号内文本
⑦ 首 token 的【前缀】决定命名空间
⑧ 条件全部通过才执行；否则整行跳过
```

## 7. 表达式引擎

三套解释器的参数都用同一个 `t` 类求值。

### 7.1 文法

```
expr    := term (('+' | '-') term)*
term    := unary (('*' | '/' | '%') unary)*
unary   := ('+' | '-') unary | primary ('^' unary)?
primary := '(' expr ')' | operand
operand := NUMBER | VARIABLE
赋值    := VARIABLE '=' expr
```

运算符字符集 `+-*/%^=()`；标识符首字符 `_ $ a-z A-Z`，其余为「非运算符非空格」。

### 7.2 Python 移植

`2-工具/formats/expr.py`，已通过 34 组用例（含 9 组错误用例）：

```python
from formats.expr import evaluate, Expr
evaluate("(atk*(5+5*slv))/30", atk=91, slv=1)   # -> 30
e = Expr(); e.set("lv", 5); e.eval("lv*10+20")    # -> 70
```

### 7.3 ★ 必须复刻的 7 个语义细节

| # | 规则 | 原因 |
|---|---|---|
| 1 | `-2^2 == 4` | 一元负号先作用于底数再做幂（`t.java:129-148`） |
| 2 | `-10/3 == -3`（不是 -4） | Java 整数除法向 0 截断 |
| 3 | `-10%3 == -1` | Java 取模符号跟随被除数 |
| 4 | `2^-1 == 0`、`2^0 == 1` | 原实现用 for 循环连乘，负指数直接落 0 |
| 5 | 未定义变量取 **0** | `t.java:170 object == null ? 0L` |
| 6 | `x/0`、`x%0` 抛异常 | `t.java:94,100` |
| 7 | 每个 `t` 实例变量表独立 | `t.java:13` |
